# Weather App 🌦️

Aplicación web desarrollada con **React + Vite** que consume una **API pública de clima** para mostrar información meteorológica en tiempo real.

## 🚀 Características
- Búsqueda de ciudades y visualización del clima actual.
- Datos obtenidos desde una API pública (ej. OpenWeatherMap).
- Interfaz responsive y minimalista.
- Información básica: temperatura, humedad, viento y estado del cielo.

## 🛠️ Tecnologías
- React
- Vite
- HTML + CSS
- API pública de clima
